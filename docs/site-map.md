# Site Map

Detailed page inventory with purpose, key elements, and content sources for each page.

## Top level

### `/` — Home
**Purpose**: Front door. Tells the student what's here and how to use it.
**Key elements**: brief intro to the course, four-frame badge cards linking to frames explainer, featured case study, "How to use this site" three-step block, search bar (Pagefind).
**Build from**: `src/pages/index.astro`.

### `/about`
**Purpose**: About Joe, the editorial policy summary, AI disclosure, contact/takedown email.
**Build from**: `src/content/pages/about.md`.

## Framework explainer pages

### `/conceptual-framework`
**Purpose**: Explain the four agencies — artist, artwork, world, audience — and the relationships between them. The "agencies" diagram. How to apply it in writing.
**Build from**: `src/content/pages/conceptual-framework.md`.

### `/frames`
**Purpose**: Index of the four frames with a one-paragraph summary of each linking to the detail page.
**Build from**: `src/content/pages/frames.md`.

### `/frames/[frame]`
**Purpose**: Detail page per frame.
- `subjective` — feelings, intuition, psychology, personal/biographical interpretation.
- `cultural` — class, race, gender, ethnicity, politics, social context, time.
- `structural` — signs, symbols, materials, formal elements, composition, conventions.
- `postmodern` — appropriation, irony, parody, recontextualisation, blurring of high/low, questioning of "originality".

Each page: definition, key questions students ask of works through this frame, vocabulary list, links to case studies whose `primaryFrame` matches.
**Build from**: `src/content/pages/frames/[frame].md`.

### `/practice`
**Purpose**: The three practices in the syllabus.
- **Artmaking practice** — intentions, materials, conceptual concerns of artists making work.
- **Art criticism practice** — how critics interpret and judge art.
- **Art history practice** — how historians place art in context across time.

**Build from**: `src/content/pages/practice.md`.

## Case studies

### `/case-studies`
**Purpose**: Filterable index of all case studies.
**Filters**: by frame (primary), by content area, by nationality (Australian / International), by century, by medium.
**Card content**: hero image, artist name + dates, primary frame badge, content area badges, short pitch.
**Build from**: `src/pages/case-studies/index.astro` reading the `case-studies` collection.

### `/case-studies/[slug]`
**Purpose**: The flagship template (see PLAN.md §6).
**Sections**:
1. Hero
2. At-a-glance bar (frame badges, content areas, content warning if needed)
3. Conceptual Framework summary block
4. Artist Practice
5. Artwork 1 — full four-frame analysis
6. Artwork 2 — full four-frame analysis
7. Linked HSC questions (real past papers)
8. Linked lessons
9. References + image credits
10. Last reviewed metadata

**Build from**: `src/content/case-studies/[slug].mdx`.

## Lessons

### `/lessons`
**Purpose**: Filterable index of lessons by year level (11 / 12), by linked case study, by topic.
**Build from**: `src/pages/lessons/index.astro`.

### `/lessons/[slug]`
**Purpose**: Lesson page with WALT, WILF, scaffolds (see PLAN.md §6).
**Build from**: `src/content/lessons/[slug].mdx`.

## HSC questions

### `/questions`
**Purpose**: Library index with four ways to browse.
**Build from**: `src/pages/questions/index.astro`.

### `/questions/by-frame/[frame]`
**Purpose**: All questions tagged with this frame. `subjective | cultural | structural | postmodern`.

### `/questions/by-content-area/[area]`
**Purpose**: All questions tagged with this content area (`body`, `place`, `identity`, `time`, `memory`, `objects`, `nature`, etc. — final taxonomy in `docs/content-model.md`).

### `/questions/by-year/[year]`
**Purpose**: All questions from a given HSC year. `2015`, `2016`, ..., `2025`.

### `/questions/by-type/[type]`
**Purpose**: All questions of a given type. `short-answer` (Section I) | `extended-response` (Section II).

### `/questions/[id]`
**Purpose**: Individual question page with scaffold, marker's view, exemplar structure, linked case studies, source link to NESA PDF.
**Build from**: `src/content/questions/[id].md`.

## Reference

### `/glossary`
**Purpose**: Alphabetised list of terms with definitions. Each term renders a hash anchor so MDX content can deep-link `[appropriation](/glossary#appropriation)`.
**Build from**: `src/content/glossary/*.md` aggregated.

### `/references`
**Purpose**: Auto-built master bibliography from every entry's `sources` array. Sorted alphabetically by author, with backlinks to entries that cite each source.
**Build from**: Astro build script that walks all collections.

## Utility

### `/404`
**Purpose**: Friendly 404 that surfaces the search bar.

### `/sitemap.xml`
**Purpose**: Generated by `@astrojs/sitemap`.

### `/rss.xml`
**Purpose**: Feed of newly published / updated case studies, for the keen.
